# AI Job Recommendation Portal

##STEPS TO EXECUTE
Follow the steps below to run the AI Job Recommendation & Recruitment Portal successfully.
 
 #Step 1: Install Python
1.	Download and install Python 3.8 or above.
Download: https://www.python.org/downloads/ 
2.	Verify installation using: 
python --version

 #Step 2: Install Required Libraries
1.	Open terminal or command prompt. 
2.	Navigate to the project folder. 
3.	Install all required dependencies using: 
py -m pip install -r requirements.txt
Required packages include:
•	Flask 
•	Pandas 
•	NumPy 
•	Scikit-learn 
•	NLTK 
•	PyPDF2 
•	Matplotlib 

 #Step 3: Project Folder Setup
Ensure the following folders and files are available:
project/
│
├── app.py
├── requirements.txt
├── templates/
├── static/
├── data/
│   ├── jobs.csv
│   ├── courses.csv


 #Step 4: Run the Flask Application
1.	Open terminal inside the project directory. 
2.	Execute the Flask application: 
python app.py
or
py app.py

 #Step 5: Access the Application
1.	After running the server, Flask will display a local URL such as: 
http://127.0.0.1:5000 
2.	Open the URL in any modern web browser. 
3.	The AI Job Recommendation Portal dashboard will load successfully.
