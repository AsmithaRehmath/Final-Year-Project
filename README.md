# AI Job Recommendation Portal

# Abstract
An intelligent system that recommends jobs and courses based on user skills using NLP and cosine similarity.

## Problem Statement
Students struggle to find suitable jobs matching their skillsets.

## Architecture
Flask + ML (TF-IDF, Cosine Similarity)

## Modules
- Resume Parser
- Job Recommender
- Skill Gap Analyzer
- Course Recommender

## Tools Used
Python, Flask, Scikit-learn, Pandas

## Conclusion
Helps students choose the right career path.
